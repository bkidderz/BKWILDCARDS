# ============================================================
# CASSETTE FUTURISM OUTFITS - KREA2 (natural-language prose)
# Retrofuturist 1970s-1990s analog sci-fi, the "used future":
# molded beige/grey plastic, analog dials and toggles, monochrome
# green/amber segment readouts (non-glowing), tube-and-cable connectors,
# sewn patches and stenciled IDs, boxy shoulders, scuffed and worn.
# Distinctly NOT cyberpunk: no neon, chrome, holograms, glowing LEDs,
# RGB, OLED/AR overlays, sleek cybernetics, or neural ports.
# Color: Lever A department/rank coding on crew archetypes, Lever C warm
# 1970s domestic-retro palette on civilian/utility. Explicit fabric/fiber
# (cotton, wool, polyester, nylon, rubber, etc.) plus weave/texture.
# Weapon-free. Gender-neutral. One outfit per line. 14 archetypes.
# ============================================================
